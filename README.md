# supervised-machine-learning

**1. Objective**

Implement supervised machine learning algorithms using Scikit-learn.

**2. Algorithms**

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors

**3.  Dataset**

Amazon Product Dataset (`amazon.csv`)

**4.  Regression**
Linear Regression is used to predict product ratings.

**5. Classification**
Products are classified as highly rated or not highly rated.

A product with a rating of 4.0 or above is considered highly rated.

**6. Evaluation Metrics**

1. Regression
- MAE
- RMSE
- R2 Score

2. Classification
- Accuracy
- Precision
- Recall
- F1 Score

**7. Technologies**

- Python
- Pandas
- NumPy
- Scikit-learn
